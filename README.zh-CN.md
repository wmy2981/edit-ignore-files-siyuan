# 编辑同步忽略

**中文** · [English](README.md)

一个思源笔记插件：用带行号的编辑器编辑数据同步忽略列表（`data/.siyuan/syncignore`），不用再去文件管理器里手改。

## 功能

- 点一下就编辑：插件列表里的「设置」直接打开编辑器，没有多余的设置面板。
- 思源原生 UI：使用宿主的 `Dialog` 与 `b3-button` 样式，移动端抽屉沿用宿主的抽屉类名、抓手与拖拽阈值，不自己造窗口外观。
- 行号编辑器：行号与正文严格对齐，长行横向滚动而不折行。
- 编辑指导：一行可折叠的说明，讲清语法并给出示例，点开才展开。
- 语法错误提示：只报会让规则失效的写法（无效反斜杠转义、圆括号或字符类没闭合、`+` 与 `{…}` 重复写法非法、字符类里含 `*`、字符类范围反了、只有 `!` 没有内容），不做风格建议，也不阻断保存。
- 精确读写：保存前重读文件比对，写回的只有你在编辑器里看到的内容，写完再读一次确认落盘结果。其它工具写入的行原样保留。
- 未保存保护：取消、点遮罩、按 `Esc`、下拉关闭都会先确认。
- 移动端抽屉：与思源原生抽屉一致——同款抓手、同样按视口算高度、同样的入场时序和下拉关闭阈值，可拖动调高。

## 使用

1. 打开 `设置 → 集市 → 已下载 → 编辑同步忽略`。
2. 点击该项的「设置」图标，编辑器直接打开。
3. 修改规则后点击 `保存`。

## 规则语法

每行一条规则，以 `data` 目录为基准，采用 gitignore 语法：

| 写法 | 含义 |
| --- | --- |
| `# 说明` | 注释 |
| `/assets/` | 忽略整个 `data/assets` 目录 |
| `/assets/*.pdf` | 忽略 `data/assets` 下直接的 PDF |
| `**/temp/**` | 忽略任意层级的 `temp` 目录 |
| `!assets/manual/*.pdf` | 取消前面某条忽略 |

建议规则以 `/` 开头，避免误匹配更深的同名路径；路径分隔符用 `/`，不要用 `\`。

思源自己还会追加几条内置规则（`/.siyuan/conf.json`、用户指南数据、`/storage/view-state.json` 等），这些不会出现在文件里，本插件也不会写入它们。

## 说明与限制

- 保存会立即写文件，但规则在下次数据同步时才生效；插件不会替你启动同步。
- 思源在加载规则前可能会改写这个文件（清理外观隔离块）。若编辑期间发生改写，保存前会先确认再覆盖。
- 不自动修规则、不做备份：你看到的内容就是写入的内容，其它工具或插件写入的规则不会被改掉。
- 移动端抽屉需要思源 3.8.10-alpha.5 及以上（宿主的抽屉样式从该版本才有）；更早的版本上是普通居中对话框，且无法拦截移动端返回手势。
- 文件带 UTF-8 BOM 时，保存会去掉 BOM：内核不会剥掉它，会把 BOM 当成第一条规则的一部分，导致第一条规则失效。打开编辑器时会给出一行提示。
- 插件只读写 `data/.siyuan/syncignore`，不碰其它文件。

## 开发

```bash
npm ci              # 安装依赖
npm run typecheck   # 类型检查
npm test            # 单元测试（不依赖思源实例）
npm run build       # 生产构建，输出 dist/ 与 package.zip
npm run verify:package # 核对 package.zip 的内容
npm run dev         # watch 构建
npm run render:icon # assets/icon.svg → assets/icon.png
npm run render:preview # assets/preview.html → assets/preview.png
```
