# 编辑同步忽略

**中文** · [English](README.md)

一个思源笔记插件：用带行号的编辑器编辑数据同步忽略列表（`data/.siyuan/syncignore`），不用再去文件管理器里手改。

![预览图](https://gcore.jsdelivr.net/gh/wmy2981/edit-syncignore-siyuan@dev/assets/preview.png)

## 功能

- 只注册一个设置：插件设置面板里的一个按钮，点击打开编辑器，不做其他事情。
- 思源原生 UI：直接使用宿主的 `Dialog` 与 `b3-button` 样式，不自己造窗口外观。
- 行号编辑器：行号与正文严格对齐，长行横向滚动而不折行。
- 编辑指导：面板里一行可折叠的说明，讲清语法并给出示例，点开才展开。
- 轻量语法提示：缺前导 `/`、反斜杠、重复行、行尾空白会在指导下方列出，只提示、不阻断保存。
- 精确读写：保存前重读文件比对，写回时不改动其它内容，写完再读一次确认落盘结果。其它工具写入的行原样保留。
- 未保存保护：取消、点遮罩、按 `Esc`、下拉关闭都会先确认。
- 移动端抽屉：思源 3.8.10-alpha.5 及以上是带抓手、可拖动调高、可下拉关闭的原生底部抽屉；更早的版本与桌面端是普通对话框。

## 使用

1. 打开 `设置 → 集市 → 已下载 → 编辑同步忽略 → 设置`。
2. 点击 `编辑忽略规则`。
3. 修改规则后点击 `保存`。

## 规则语法

每行一条规则，以 `data` 目录为基准，采用 gitignore 语法：

| 写法 | 含义 |
| --- | --- |
| `# 说明` | 注释 |
| `/assets/` | 忽略整个 `data/assets` 目录 |
| `/assets/*.pdf` | 忽略 `data/assets` 下直接的 PDF |
| `**/temp/**` | 忽略任意层级的 `temp` 目录 |
| `!assets/manual/*.pdf` | 取消前面某条忽略 |

建议规则以 `/` 开头，避免误匹配更深的同名路径；路径分隔符用 `/`，不要用 `\`。

思源自己还会追加几条内置规则（`/.siyuan/conf.json`、用户指南数据、`/storage/view-state.json` 等），这些不会出现在文件里，本插件也不会写入它们。

## 说明与限制

- 保存会立即写文件，但规则在下次数据同步时才生效；插件不会替你启动同步。
- 思源在加载规则前可能会改写这个文件（清理外观隔离块）。若编辑期间发生改写，保存前会先确认再覆盖。
- 不自动修规则、不做备份：你看到的内容就是写入的内容，其它工具或插件写入的规则不会被改掉。
- 移动端抽屉需要思源 3.8.10-alpha.5 及以上（宿主的抽屉样式从该版本才有）。更早的版本上是普通居中对话框，且无法拦截移动端返回手势。
- 插件只读写 `data/.siyuan/syncignore`，不碰其它文件。

## 手动验证

静态检查（不需要启动思源）：

```bash
npm ci
npm run typecheck
npm run build
```

真实环境检查（请使用独立临时工作空间）：打开插件设置，点击按钮，改一条规则并保存，确认磁盘文件内容与下次同步的效果。移动端重复一遍，检查抽屉能打开、能拖动调高、能下拉关闭，且未保存改动会确认。
